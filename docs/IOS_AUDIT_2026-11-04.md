# Audyt AutoLogika OS — iOS / Safari PWA

Data: 2026-11-04. Bazowa wersja: `d9e3b120204b58e96334b656b8d5abd93b3cf19a`.

## Zakres i dowody

Przegląd wszystkich 23 ekranów menu, adaptera PWA, kontraktów danych Windows, Auth/REST/Storage, synchronizacji, formularzy i Service Workera. Testy używają izolowanego konta i danych testowych; nie wprowadzają rekordów do produkcyjnego Supabase. Rozmiar widoku telefonu: 430 × 932. Chromium/Electron nie zastępuje Safari ani fizycznego aparatu iPhone'a.

## Ograniczenia i pozostałe prace

- **Wersjonowane kosztorysy i ich akceptacja:** `quotes` i `quote_items` nie należą do obecnego wspólnego kontraktu synchronizacji desktopu. PWA pokazuje roboczy zakres oparty o `order_items`. Dotychczasowe pozorne operacje tworzenia wersji i zatwierdzania zostały zastąpione komunikatem, że wymagają Windows. Pełne wdrożenie wymaga wspólnego kontraktu wersji/snapshotów i powiązań akceptacji; nie wolno traktować tego jako ukończonego.
- **Równoczesna edycja na różnych urządzeniach:** klient wykrywa konflikty na podstawie aktualnego nagłówka rekordu, ale między sprawdzeniem a zapisem pozostaje okno wyścigu. Bezwzględna gwarancja wymaga serwerowego compare-and-swap/RPC. Nie wdrażano zmian schematu produkcyjnego Supabase.
- **Magazyn:** rezerwacja, wydanie, zwrot i montaż pozostają funkcjami Windows do czasu wspólnej transakcji serwerowej. Kontrola kolizji terminarza jest również kontrolą klienta i nie gwarantuje globalnej blokady w tej samej milisekundzie.
- **Kartoteka pracowników, lokalna wiedza, Ollama, lokalny OCR, archiwum SQLite/EXE:** nie są częścią pełnej synchronizacji PWA. Timer iOS obsługuje właściciela. Nie deklarujemy synchronizacji lokalnej bazy wiedzy ani pracowników.
- **Web Push:** nadal wymaga backendu subskrypcji i wysyłki. Centrum uwagi w aplikacji jest odczytywane z rekordów, nie jest powiadomieniem systemowym iOS.
- **Offline:** cache obejmuje powłokę i zasoby aplikacji; nie ma trwałego bufora pełnej bazy klientów ani kolejki offline zapisów.
- **Poprawki importerów Windows** z tego audytu wymagają aktualizacji aplikacji Windows. Sama publikacja PWA nie zmienia zainstalowanego EXE.
- **Do testu na fizycznym iPhonie:** aparat/AZTEC i odmowa uprawnień, HEIC/HEIF, biblioteka zdjęć, Web Share, druk/PDF, instalacja standalone i aktualizacja po długim uśpieniu.

- `node --test tests/*.test.mjs`: testy modeli, API PWA, sesji, relacji, konfliktów, snapshotów i terminarza.
- `node --test tests/sync-repair-links.test.cjs`: round-trip relacji naprawy oraz starsze metadane zdjęć iOS.
- Pełne `npm test`, build, manifest/SW i test 23 ekranów: workflow `iOS PWA` na gałęzi audytu przed publikacją.
- Lokalny proces Chromium jest ograniczony przez środowisko (`socket(): Operation not permitted`); test przeglądarki wykonuje runner GitHub z izolowaną atrapą REST, bez wyjścia do danych produkcyjnych.
